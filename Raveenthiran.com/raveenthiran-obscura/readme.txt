A single-screen, no-scroll photography portfolio theme — the Obscura design system.

== Description ==
Warm near-black canvas, bone-white type, one sodium-amber accent; Inter Tight +
JetBrains Mono (self-hosted). Fullscreen hero with dot-constellation navigation,
horizontal card rails for Work and Journal, page-wipe transitions and refined
editorial composition. Plugin-light: built-in SMTP, WebP delivery, dynamic OG
share cards, dependency-free PDF estimates, Cloudflare Turnstile, Leaflet map,
enquiry insights and a theme-health dashboard. Compatible with ACF Pro (optional).

== Installation ==
1. Appearance → Themes → Add New → Upload Theme → choose the ZIP → Activate.
2. Follow the on-screen onboarding notice (create pages, save permalinks, fill
   Theme Settings). See SETUP.md for details.

== Frequently Asked Questions ==
= Does it require any plugins? =
No. ACF Pro is optional (a polyfill runs the theme without it).

= How do I make email reliable? =
Theme Settings → § Mail (SMTP). See SETUP.md for the Google Workspace + DNS steps.
