Intro video
===========
Drop your intro clip here as one of:

    intro.mp4      (recommended — H.264/AAC, muted, ~5–10s)
    intro.webm
    intro.mov

As soon as the file is present, the front-page intro plays it full-screen,
shows the "Scroll right" cue, then slides right into the home preview.

With no file here, the intro falls back to the animated boot / terminal /
name-decode sequence automatically. No code changes needed either way.

Tips: keep it short and muted (browsers block autoplay with sound). A 1080p
or 720p file a few MB in size keeps the page fast.
